The Idea of this project is to have a FROM Section and a To Section which can be minimized and can be shown the value -> which is the state

First version will have the hardcoded values from INR to these To Section
I will provide some icons to choose from like US Dollar, UK Pound, Canadian Dollar, etc.

The next version will make api calls to fetch real data by useEffect hook, and we can store it in a state management library, like context api or even server state using React Query
